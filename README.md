# Machine-Learning-

This folder contains data analysis projects completed using Python. The projects focus on exploring datasets, identifying relationships, and using machine learning methods to understand the data. 

## Projects:

- Employee Productivity Analysis: Analyzed employee and workplace factors to identify variables associated with employee productivity. Used exploratory data analysis, statistical analysis, and machine learning to examine the relationships.

  
- Wine Analysis: Explored wine characteristics and relationships using Python. Used Data Visualization and statistical analysis to identify patterns and understand factors associated with wine to make predictions.
